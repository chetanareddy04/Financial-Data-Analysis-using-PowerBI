#  Financial Data Analysis | Power BI

## Project Overview

An interactive Power BI dashboard designed to analyze company financial performance using annual and quarterly financial statements. It provides insights into revenue, expenses, profitability, cash flow, assets, liabilities, and key financial KPIs to support data-driven decision-making.

##  Objectives

* Analyze financial performance across companies and years.
* Track revenue, expenses, and profitability trends.
* Evaluate cash flow and financial stability.
* Understand asset, liability, and equity distribution.
* Build interactive dashboards for financial insights.

##  Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPI calculations
* **Data Modeling** – Organizing financial statement data

##  Dataset

The project includes six financial datasets:

* Annual Income Statement
* Quarterly Income Statement
* Annual Cash Flow Statement
* Quarterly Cash Flow Statement
* Annual Balance Sheet
* Quarterly Balance Sheet

## Methodology

1. **Data Collection:** Imported annual and quarterly financial datasets.
2. **Data Cleaning:** Handled missing values, checked data types, and examined duplicates and outliers.
3. **Data Transformation:** Prepared and structured the datasets using Power Query.
4. **Data Modeling:** Organized financial data for interactive analysis.
5. **DAX Calculations:** Created measures for financial KPIs and performance analysis.
6. **Visualization:** Developed interactive dashboards with charts, KPI cards, slicers, and navigation buttons.

## Key Insights

* Compared financial performance across companies and reporting periods.
* Analyzed revenue, expenses, and profitability trends.
* Evaluated operating cash flow and cash flow patterns.
* Examined assets, liabilities, debt, and shareholders' equity.
* Compared key financial indicators to understand company performance.
